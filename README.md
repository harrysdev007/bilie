# $Billie

React 19 and Vite website for an independent Billie Brightpaw fan meme project on Solana.

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:5173/. To create the production build, run `npm run build`. Output is in `dist/`.

## Launch links

Edit `src/config.js` to change X or add the verified Solana contract and direct pump.fun URL. The current site honestly shows an upcoming launch until a contract is configured. No wallet connection or token transaction is implemented.

## Features

Responsive layout, animated poster and marquee, countdown to November 26, 2026 at 8:30 AM New York time, sourced character story, independent fan disclosure, FAQ, opt-in celebration sound, confetti and downloadable meme creator.

The attached user image is used for the logo, favicon, hero and meme creator. Additional photographs come from Good Housekeeping's article linked in the interface. Character rights belong to their owners. Font families: Anton, Bricolage Grotesque, Caveat. Libraries: Motion, Lucide React, canvas-confetti.
